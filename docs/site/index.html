产品介绍

ragagent-java 是 WeKnora（腾讯开源的知识检索与分析系统）后端的 Java 全量翻译版——把 Go（Gin/GORM）后端逐文件翻译为 Spring Boot 3.3 / JDK 21 / MyBatis-Plus，前端零改动复用。

本项目的验收标准是行为字节级一致：同一请求打到 Go 参考实现与 Java 实现两侧，响应体（JSON 键序、HTML 转义、SSE 帧格式、错误文案、时区渲染）必须逐字节相同。为此建立了 1,748 个 golden 契约测试与 75 个双端 A/B 脚本，HTTP 路由面已全量翻译（程序化对账后唯一留白为 Go 工具路由 /swagger/{}，属非翻译目标）。

上游持续演进时，本项目以 行为等价 为对齐目标：功能对照以 Go 仓为参考实现，本仓文档描述的是 Java 侧的部署与使用。

技术栈

层选型
运行时JDK 21（虚拟线程：检索并发、工具并行、租户上下文显式拷贝）
框架Spring Boot 3.3.5 · MyBatis-Plus 3.5.7 · Flyway（196 个迁移）
存储PostgreSQL 17 / ParadeDB（pgvector HNSW + BM25 · RRF 融合）、Redis 7（stream/绑定/限流）

沙箱docker-java 3.7.1（zerodep 传输）：技能安装管线 + 镜像快照 + 产物排水
前端Vue 3.5 + Vite 7（从上游原样复制）

安装部署

前置：JDK 21、Docker、Node 20+。

# 1) 基础设施：postgres/ParadeDB(15432) + redis(16379) + docreader(50051)
docker compose up -d

# 2) 密钥与连接配置（.env 已 gitignore，必需键见 scripts/dev-env.sh 头注释）
#    JWT_SECRET / SYSTEM_AES_KEY / DB_* / REDIS_* / LOCAL_STORAGE_BASE_DIR …

# 3) 后端（默认 :8082）
./gradlew bootRun
#    或带就绪等待：scripts/java-server-up.sh

# 4) 前端（:5173，代理显式指向 Java 后端）
cd frontend && npm ci
VITE_DEV_PROXY_TARGET=http://localhost:8082 npm run dev
ParadeDB 镜像内含 pgvector 与 BM25 索引能力，是混合检索的依赖；普通 postgres 镜像会使向量/关键词检索退化为空。

现象原因与处理

架构

总体架构

单 Spring Boot 进程（37 个领域包）+ ParadeDB/Redis/docreader 基础设施 + Docker 沙箱执行面；前端零改动，只认 HTTP/SSE 契约。

▲ 交互式架构图（可切换视图 / 明暗主题 / 导出）——由 docs/architecture.json 经 Archify 生成，改架构后重跑 node ~/.zcode/skills/archify/bin/archify.mjs deliver architecture … 即可。

契约驱动的翻译方法论

37 个领域包与 Go 仓 internal/* 存在系统性映射（handler → controller、application/service → service、application/repository → mapper、types → domain、models → llm、middleware/router → common/web + config/WebConfig）。这套 1:1 映射让每一批翻译都可审计：看 Java 文件名即知 Go 原文位置。

验收的三条铁律

层次手段规模
golden 契约测试MockMvc 掩码后逐字节比对（UUID/时间戳等动态字段除外）1,748 个实录
双端 stub A/B双端同指 stub LLM 走真实 HTTP/SSE 全链路，agent 出站请求体已可全 body 对拍75 个脚本
真实集成dev PostgreSQL（jsonb/NOT NULL/时区差异）+ Docker 沙箱 IT + 产物排水全链 IT按门控启用

LLM 出站体按 Go 的两条真实路径分流序列化：prompt-cache 改写路径为 map 字节序，SDK 直出 / thinking 包装路径为 openai-go 结构体声明序——两条路径均与 Go 逐字节对拍验证。

检索问答全流程

阶段行为
1 · 查询理解意图分类、改写、（低召回时）本地变体扩展
2 · 混合检索pgvector HNSW 向量检索 + ParadeDB BM25 关键词检索，RRF 融合排序
3 · FAQ 优先级FAQ 命中（阈值达标）直出标准问答，否则并入普通引用
4 · 重排与富化rerank 模型重排、图片信息富化、引用装配
5 · 生成快答管线直出；Agent 模式进入 AgentEngine 工具循环（知识检索 / wiki / 网络搜索 / 沙箱 / MCP）
6 · 回包SSE 契约层分帧（final_answer 分片重组、steer 插话、产物挂载），异步落库与标题/追问建议生成

文档入库流程

阶段行为
1 · 上传文件落存储后端，knowledge 行进入处理队列
2 · 解析docreader gRPC 抽取结构化内容（可观测：spans 时间线，前端可查 Trace）
3 · 分块chunker 父子分块（可预览），FAQ 走问答对形态
4 · 索引向量入库（halfvec HNSW）+ BM25 索引；失败有清理与重试语义
5 · 后处理摘要 fan-out（依赖 KB 配置的 summary model）、问题生成

验收体系与回归纪律

全量测试按域分批执行（同一 JVM 全量会触发 Mockito self-attach 风暴）；Docker 集成测试由 WEKNORA_SANDBOX_DOCKER_IT=true 门控，覆盖容器执行面与产物排水全链（容器 → 收集器 → resource:// 注册 → 磁盘回环 → 去重与引用历史）。

跑 ./gradlew test 会重写 bootRun 正在使用的 build/classes——运行中的服务随即全站 500（NoClassDefFoundError），重启服务即解。
