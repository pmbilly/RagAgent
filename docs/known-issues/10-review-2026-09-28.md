## 二、有意降级/确认无问题的误报（后续评审勿重复报）

- **api-principal test token 字符串 tenant_id**：Jackson ≥2.15 起 `TextNode("123").canConvertToLong()` 为 true（仓内 2.17.2），签发→校验闭环可用，非 bug。
- **RRF 租户配置"零消费"**：`HybridSearchService` 经 JsonNode 动态读 `rrf_k/rrf_vector_weight/rrf_keyword_weight`，不走 `RetrievalConfig` 的 getter。
- **event 包六个未引用类**（AgentPlanData/AgentStepData/ChatData/RerankData/MergeData/EventMiddleware）：`EventPayloadJsonTest`/`EventMiddlewareTest` golden 钉住的 Go 同形预留，非遗漏。
- **CORS `*` + allowCredentials**：Go 同源继承项；认证走 Authorization 头，实际可利用性低。

## 三、测试环境备忘

homebrew OpenJDK（21/26）默认拒绝 Mockito inline 的自挂 attach，全量测试会按
`MockitoInitializationException → AttachNotSupportedException` 批量假失败。
`server/build.gradle.kts` 的 test task 已把 `byte-buddy-agent` 挂为 `-javaagent`
（其 Installer premain 先装好 Instrumentation，Mockito 不再走 attach）——
换 JDK/升级 Mockito 时留意；若整体假失败先查这里，别当成业务回归。
