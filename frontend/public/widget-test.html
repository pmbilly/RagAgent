Embed Widget 测试页

验收清单

  • 右下角应出现 黑色 圆形启动按钮（primary color #000000）
  • 点击展开聊天窗，默认尺寸 420 × 720
  • 标题为「GAC AI 客服」
  • 发消息测试用户消息气泡样式（深底白字 14px）
  • 渠道「显示思考过程」关闭时：思考中只见三点闪烁
  • 渠道「显示思考过程」打开时：「思考中」折叠卡片，展开为 markdown

说明

本页与 widget 脚本同源（均来自 vite dev server），页面 origin 为 http://localhost:5173，需已加入渠道的 Allowed Origins， 否则会报 origin not allowed。
